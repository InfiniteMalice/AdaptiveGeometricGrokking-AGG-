# Roadmap

The current release is a CPU-runnable research scaffold. Implementation availability and smoke verification are distinct from scientific milestone completion.

| Stage | Existing support | Evidence still needed |
|---|---|---|
| Grokking reproduction | Modular task, causal Transformer and training checkpoints | Replicated delayed generalization curves under a published protocol |
| Telemetry | Versioned snapshots, spectra, depth derivatives and JSONL | Stability, redundancy and sensitivity studies across seeds/samples |
| Retrieval crossing | Independent evidence scores, executed probes and sustained crossings | Probe calibration controls and a replicated factorial phase surface |
| Geometry | Euclidean/Poincare/product distance adapters and dimension candidates | Matched-budget hierarchy advantage, distortion and sufficiency curves |
| Gate causality | Fixed/learned gates and exact zero bypass | Gate sweeps controlling weights, initialization and training exposure |
| Consolidation | Proposal/trial separation and independent feasibility constraints | Benefit over equal-update continued training with untouched test sets |
| Compression | Pruning, low-rank function and rounding candidates | Identical checkpoint-class sweeps and robust component precision floors |
| Physical storage | Exact reference codecs and measured CPU selection | Optimized kernels and complete-model deployment benchmarks |
| Executable credit | Real deterministic traces, conflicts and discounted returns | Trained agents and causal delayed-outcome experiments |
| Complexity | Explicit predictive-code-length proxy | Validated structural epiplexity estimator and predictive utility controls |

Near-term scientific work should first validate baseline task difficulty and probe discriminability. Then preregister the experiment matrix, collect full trajectories, and evaluate interventions on independent final tests. Offline persistence, manifold trajectories, richer causal patching, change-point inference and uncertainty analysis can extend the scaffold after their cost and construct validity are demonstrated.

LLM-scale training, arbitrary manifolds, per-token geometry routing, neural ODE conversion, production ternary kernels and distributed infrastructure are outside v0.1 scope. Do not relabel a missing scientific outcome as complete because the relevant module exists.
