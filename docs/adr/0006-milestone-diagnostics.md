# ADR 0006: Milestones consume evidence without granting optimization authority

Status: accepted for opt-in research integration.

Use typed source measurements and four explicit property definitions. Compose
frozen training, causal audit and independent audit artifacts in a separate
report. Reuse sustained-crossing logic and preserve missing/conflicting evidence,
reversals and observed brackets. These properties need not be monotonic or ordered.

Require full-stratum balanced hierarchy accuracy to prevent majority-class
performance from qualifying as generalization. One post-selection parameter
compression observation remains insufficient for sustained confirmation. Keep
physical resources outside this diagnostic's parameter-count definition.

No reward adapter is justified: temporal associations over tiny dependent
trajectories do not establish milestone validity. Future held-out validation may
test the hypotheses, but telemetry never directly authorizes a model update.
