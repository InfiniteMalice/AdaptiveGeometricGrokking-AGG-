# ADR 0007: Ground summaries as executable, scoped task rules

Status: accepted for opt-in research integration under the existing model interface.

TinyTransformer has no prose channel. Use bounded oracle-checked augmentation
templates as candidate lessons and preserve source episodes, contradictions and
future utility in AbstractionRegistry. This is a controlled executable-summary
experiment, not a new memory implementation or language reasoning claim.

Reuse copy trials and per-block original anchors for every retained update.
Independent audit stays inaccessible until all blocks and curation decisions are
frozen. Later selection data may guide subsequent lesson use; it does not become
scientific confirmation. Active lessons must be ablated out of their own marginal
reference. Negative controls never update a retained lineage or knowledge authority.

A common model with predeclared task token namespaces/output head supports family
switches without resetting learned weights. Left padding fixes actual token
budgets, so logical context lengths cannot be claimed as compute savings. The
curriculum gate remains a recorded recommendation during the fixed-budget study.

Hierarchy query symbols are normalized across depths before model input, independently of raw oracle encoding, to avoid delimiter/node embedding collisions.
