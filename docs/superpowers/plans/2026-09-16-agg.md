# AGG Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent
> subsystem implementation and review; integrate and verify in this session.

**Goal:** Implement the approved research design as a tested local open-source repository.
**Architecture:** Explicit data generators, a baseline model, observational telemetry,
copy-based intervention trials, independent constraints, and inspectable artifacts.
**Tech Stack:** Python 3.12+, PyTorch, NumPy, pytest, Ruff, mypy; optional Geoopt/ripser.
**Spec:** ../../specs/implementation.md and ../../specs/approved-research-brief.md.

## Global constraints

Understand → Restructure → Compress → Verify. Hypotheses remain hypotheses.
All randomness is seeded. No silent intervention, metric substitution, or sparse
speedup claim. Every proxy is labeled; missing data is unavailable, never invented.
CPU smoke runs verify software behavior, not scientific success.
